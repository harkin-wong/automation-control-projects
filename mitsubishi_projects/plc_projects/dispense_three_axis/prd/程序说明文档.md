# 一. 需求

1. 开机流程

	1. 上电Z轴回原
	2. Z轴回原完成后, XY轴同时回原
	3. 三轴都回原完成后, XY去待机位
	4. 三轴回原完成后, 设置软限位生效

2. 手动功能

	1. 三轴JOG正负运行
	2. 三轴手动回原功能

3. 示教场景

	1. 可手动增减点胶位
	2. HMI显示点胶过程

4. 阵列场景

	1. 设置: 起点与终点; 行数与列数;
	2. 计算
		- 根据行数与列数, 计算出总点胶数
		- 根据起点与终点坐标, 计算出X向间距与Y向间距
		- 行/列索引越界保护
		- 每完成一个点位, 原始列索引加1; 当原始列索引\(\ge\)总列数时, 原始列索引清零且原始行索引加1 
		- 行索引奇偶校验: 判断蛇形翻转标记
			- 偶数行: 蛇形翻转后的有效列 = 当前列索引
			- 奇数行: 蛇形翻车后的有效列 = 总列数 - 1 - 当前列索引
		- 目标X坐标 = 起点X坐标 + 蛇形翻转后的有效列 * X向间距
		- 目标Y坐标 = 起点Y坐标 + 原始行索引 * Y向间距
		- 当前点胶数统计, 当前点胶数\(\ge\)总点胶数, 点胶结束
	3. HMI显示点胶过程

5. 暂停与复位功能: 复位只有在暂停情况下才有效

	- 启动/暂停为同一个按钮(通过两个状态机结合PLC扫描周期进行控制)
		```iecst
		CASE run_state_machine OF
			0:
				// ...
				run_state_next := 1;
			// 1: 启动状态
			1:
				// ...
				run_state_next := 2;
			// 2: 暂停状态
			2:
				// 按启动, 继续运行
				// 按复位, 执行开机流程
		END_CASE;
		统一更新状态机, 避免多次连续跳转
		run_state_machine := run_state_next;
		```

		- 梯形图同样需要两个寄存器(如D1, D2), 比较用D1, 状态结束, 更新D2, D2数据同步给D1(SM400)

6. 急停功能: 无论示教/阵列, 拍下急停, 停止运行, 急停复位, 执行开机流程

# 二. 整体架构

```textplain
|-工程文件
	|- 初始型: init(初始化相关参数)
	|- 扫描型: main(主程序)
	|- 待机型: sb_startup_run(开机流程)
			  sb_jog_control(手动控制)
			  sb_teach_process(示教流程)
			  sb_snake_array_process(阵列流程)
			  sb_emergency(急停功能)
			  sb_pause(暂停复位功能)
			  sb_dispense_process(点胶流程)
```

- main主程序根据对应条件, CALL不同子程序, 逻辑拆分收敛于子程序内部
- 提高整体代码可读性, 健壮性
- 需要变更, 只迭代对应功能子程序即可
